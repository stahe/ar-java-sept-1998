1. **Programming in Java**

2. **Java Client-Server**
   سيدريك نيكولاس، كريستوف أفاري، فريديريك ناجمان – Eyrolles

* Java Beans
* JDBC
* CORBA / RMI

## إخلاء المسؤولية

عندما تمت كتابة هذه الدورة لأول مرة (1998)، لم يكن المؤلف على دراية تامة بقواعد الترميز في Java.

في ذلك الوقت:

* كانت اللغة لا تزال في مهدها.
* لم يكن هناك أي IDE يستخدم للإبلاغ عن انتهاكات قواعد التسمية.

ونتيجة لذلك:

* يجب أن تبدأ أسماء الفئات والواجهات بحرف كبير.
* لم يتم اتباع هذه القاعدة بشكل متسق في الوثيقة.

بالإضافة إلى ذلك، أصبحت العديد من التقنيات المعروضة قديمة الآن:

* RMI
* CORBA
* Swing
* Applet
* بيئة التطوير المتكاملة (IDE) JBuilder
